Orders + Picking List: one page, six layouts

Six ways to merge the Orders page and the Picking List into one compact page. Each is shown for the three roles that reach it today, so you can see exactly what each person gets and what stays hidden. Every order line now also shows the product colour, a Shopify admin link and, for Admin and Staff, the available quantity and purchase order status; Admin gets a + PO button on short lines. All concepts share the same ideas: queue tabs with live counts, one smart search, filters as chips, a stage track per order, a slip-printed filter with a green printer icon once the picking slip is printed (the old “late after 24 h” rule is now an optional extra inside that filter), one bulk bar, and the zoom control from Inventory (50–150%, Ctrl +/−/0; try it on any screen). Artboards are 1280 × 800 and need no page scroll.

All orders, customers and numbers on these screens are synthetic samples. Round 3 added what the first rounds left out (request stock, decoration, attachments, name export, fulfilment depth, picking-slip and notify dialogs): see dialogs.html for the dialogs and menus and PARITY.md for the full old-vs-new checklist.
